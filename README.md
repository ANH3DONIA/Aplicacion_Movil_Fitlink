# FitLink — App Móvil (Socio y Entrenador)

Aplicación móvil en **Expo / React Native** con roles de **Socio** y **Entrenador** para **FitLink Gym** (Proyecto Integrador · UTSLRC IDGS-9-1).

## Requisitos

- Node.js 20 o superior
- npm 10 o superior
- Android Studio (emulador) o Expo Go en dispositivo Android

## Instalación y ejecución local

```bash
npm install
npx expo start --clear
```

Comandos directos por plataforma:

```bash
npm run android
npm run web
```

## Tecnologías

- Expo + React Native + TypeScript
- Expo Router
- AsyncStorage
- Lucide React Native
